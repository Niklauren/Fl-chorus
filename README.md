# FL Chorus — recreated by mikita_laurenau

Хорус по схеме FL Studio Fruity Chorus, в формате VST3 / AU для macOS и VST3 для Windows.
Дизайн тот же, что у FL Soft Clipper.

## Как устроен (по мануалу FL Studio)

- Три голоса хоруса. У каждого своя линия задержки, которую качает собственный LFO
  в пределах от **Delay** до **Delay + Depth**.
- Формы LFO: Sine, Triangle и Multi-sine. Multi-sine — это синус плюс синус втрое быстрее.
- **Stereo** (0–360°) сдвигает LFO правого канала относительно левого.
- **Cross** решает, к какой части сигнала применяется хорус:
  - ALL — ко всему сигналу;
  - LOW — только ниже частоты **Cutoff**;
  - HIGH — только выше неё.
- **Wet Only** отключает сухой сигнал, для использования на посыле (send).

## Ручки

| Ручка | Диапазон | По умолчанию |
|---|---|---|
| Delay | 0–30 ms | 10 ms |
| Depth | 0–20 ms | 3 ms |
| Stereo | 0–360° | 90° |
| LFO 1 / 2 / 3 | 0.01–10 Hz, клик по плашке под ручкой меняет форму волны | 0.42 / 0.71 / 1.1 Hz |
| Cutoff | 20 Hz – 20 kHz | 500 Hz |

- Двойной клик по цифрам под ручкой — ввести значение с клавиатуры.
- Двойной клик по ручке — вернуть значение по умолчанию.

## Насколько это «как в FL»

Ручки и схема работы такие же, как описано в мануале FL Studio.
Точные внутренние константы Fruity Chorus Image-Line не публикует:
- диапазоны и значения по умолчанию;
- уровни сухого и обработанного сигнала;
- тип кроссовера.

Поэтому до бит-в-бит его можно довести только по рендерам из FL Studio, так же как Soft Clipper.

## Установщики

Всё как у FL Soft Clipper. Загрузи содержимое этой папки в новый репозиторий на GitHub,
включая скрытую папку `.github` (в Finder её показывает Cmd + Shift + .).
Затем открой Actions и скачай **FL-Chorus** из раздела Artifacts — это готовый zip для друзей.

Собрать у себя:
- **Mac:** `bash installer/mac/make-pkg.sh`
- **Windows:** `installer\windows\make-installer.bat`

Плагин не связан с Image-Line. FL Studio и Fruity Chorus — их торговые марки.
Шрифты Archivo и JetBrains Mono распространяются под SIL OFL 1.1.
